## 1 共用与差异

| 项 | 02 | 03 | 规则 |

### 2.4 状态与验收

- 本屏没有按钮 / 磁贴 / 芯片; 唯一可交互件是求助键, 长按 1.5s, 静态图不表现长按.

- 波形 #5FD3B8 on #06090A 对比 10.9:1, 只作图形, 不作正文.

- [ ] 160px 宽缩略图仍能读出白色主话.
- [ ] 3 米外能读出"往前走十八步".
- [ ] 除求助键外, 没有任何带边框 / 底色的可点块.
- [ ] 黑底无渐变, 无发光, 无第二强调色.
- [ ] 波形 6 根, 不压状态条, 不压主话.
- [ ] 状态条 / 页脚 / 求助键与 01 / 03 / 04 同线.

### 3.4 状态与验收

- 芯片可多选, 选中 / 取消在 80ms 内反馈; 选中不只靠底色, 右上对钩是第二信号.
- 芯片 88 高, 热区 288 x 88, 远超 88 x 88; 行距 24, 列距 32, 防误点.
- 主按钮 120 高; pressed 底色加深 8%, 不位移.
- 底部字幕是医生原话, 不是页脚; 与 01 / 04 页脚同基线 552, 七屏并排不跳.
- 求助键长按 1.5s, 静态图不表现长按.

- [ ] 6 个芯片单行不换行, 最长 7 字.
- [ ] 2 个选中芯片一眼能看出, 不靠颜色也能看出.
- [ ] 160px 宽缩略图仍能看出"6 个选项 + 1 个主按钮".
- [ ] 3 米外能读出标题"替我说".
- [ ] 主按钮 / 字幕 / 求助键三者不重叠.
- [ ] 状态条 / 页脚 / 求助键与 01 / 02 / 04 同线.
