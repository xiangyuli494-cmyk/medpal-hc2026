# 视觉系统

> 这份文档是 Figma「视觉系统」页的人话版本。改视觉先改这里，再同步到 Figma；新建屏幕不许自造颜色和字号。

## 1 气质定位

三版小样里选的是**「纸张 + 冷静信息层」**：

- 底色不是纯白也不是医疗蓝，是**暖纸色**（#F6F3EE）——像病历纸、像候诊区的木色，不刺眼、不像 App
- 主色是**深青**（#0E6E63）——比蓝更暖，比绿更稳，印刷出来也好看
- 强调色只给"要小心的事"：琥珀（提示）、暗红（求助）、安全绿（已完成）
- **全站零渐变、零玻璃拟态、零阴影堆叠**。影子只有一层，用来托起卡片

一句话：**看得清、不吓人、不像手机。**

| token | 值 | 用途 | 不许用在这 |

对比度实测: `ink-900` on `paper` = 16.1:1; `teal-600` on `surface` = 6.1:1; 白字 on `teal-600` = 6.1:1; `red-600` on `red-100` = 4.6:1; `ink-500` on `paper` = 5.1:1. 承载信息的正文 >= 7:1; 按钮文字 >= 4.5:1; `ink-500` 只用于 22px 及以上的辅助说明; `red-600` on `red-100` 只用于大图形与 22px 以上文字.

## 3 字阶（1024×600 设备屏，基准 20px）

| 层级 | 倍数 | 实际 | 用途 | 字重 |
| --- | --- | --- | --- | --- |
| display | 2.8em | 56 | 每屏唯一的一句主话 | 700 |
| h1 | 2.0em | 40 | 分区标题 | 700 |
| h2 | 1.55em | 31 | 卡片标题 | 600 |
| body | 1.32em | 26 | 正文 | 400 |
| sm | 1.1em | 22 | 次要说明 | 400 |
| cap | 0.9em | 18 | 免责、法律小字、状态条 | 400 |

规则：
- **一屏只有一个 display**。第二个 display 就是没有重点
- 数据例外: 金额 / 步数可用 56px 等宽数字成组出现, 一组不超过 3 个, 不算第二个 display; 屏 05 按此例外.
- 正文永远 26px 起，**没有更小的正文**。18px 只给免责、法律小字、状态条
- 屏内页脚 (一句安抚 / 提示) 用 22 (sm); 免责、法律小字、状态条用 18 (cap).
- 数字用等宽（`font-variant-numeric: tabular-nums`），金额、时间、步数不许跳动
- 行高：标题 1.15，正文 1.55，说明 1.6

## 4 栅格与间距

- 画布 1024×600，安全边距：左右 48px、上下 42px
- 8 的倍数：8 / 16 / 24 / 32 / 48（组件内最多到 32，超过就换布局）
- 单列为主. 两列只出现在家属端 (文字 + 手机) 和入口分流 (3 个并列磁贴); 03 的 6 个芯片是 3 x 2 等宽选项组, 不算分栏.
- 按钮间距 ≥ 24px，防误触

## 5 组件规格

| 组件 | 高度 | 圆角 | 说明 |
| --- | --- | --- | --- |
| 主按钮 `.btn--primary` | 120px | 16px | 深青实底、白字 26px（body） |
| 次按钮 `.btn--ghost` | 120px | 16px | 透明底、1.5px 边 |
| 求助键 `.btn--danger` | 88×88 | 圆形 | 暗红，**只在右下角**，长按 1.5s，每一屏都在 |
| 磁贴 `.tile` | 232px | 22px | 图标 64 + 标题 40（h1）+ 说明 22（sm） |
| 卡片 `.card` | 自适应 | 20px | 白底 + 1px 边 + 单层影 |
| 状态条 | 28px | — | 18px 灰字，左侧一个 8px 圆点 |
| 芯片 `.chip` | 88px | 16px | 白底 + 1px 边, 文字 26px; 选中 teal-100 底 + 1.5px teal-600 边 + 右上 24px 对钩, 不只靠颜色 |
| 金额宫格 `.amount` | 自适应 | 20px | 3 个等宽格, 数字 56px 等宽, 标签 22px; 格间 1px 线 |
| 提示条 `.notice` | 56px | 12px | amber-100 底 + 4px amber-600 左条, 文字 22px ink-900, 不可点 |
| 小暖 `.warm` | 96 x 96 | 圆形 | 5 表情, 见第 8 节; 放右上或提示卡左侧, 不占主视觉 |

## 6 大字模式 / 高对比模式（同一套 token，两种覆盖）

```css
/* 大字：只改根字号，全屏按 em 等比放大 */
.device__screen.is-large { font-size: 23px; }

/* 高对比：只覆盖语义变量，组件代码一行不改 */
.device__screen.is-contrast {
  --bg:#06090A; --fg:#fff; --fg-2:#D6D6D6;
  --card:#0B0B0B; --line-x:#5A5F5C;
  --accent:#5FD3B8; --accent-ink:#04110E;
}
```

02 视障语音通道固定用这套覆盖, 不是用户设置; 02 的底就是 #06090A, 白字 #FFFFFF.

这就是为什么设备内所有尺寸必须用 `em`、所有颜色必须走变量：**设计师改一个数，整屏跟着变。**

## 7 图标

12 个自绘线性图标，2px 描边，24×24 网格，圆头端点。**禁止 emoji**（跨设备渲染不一致、颜色不可控、印刷发灰）。

## 8 小暖形象

- 纯几何构成，无插画细节：圆头 + 两点眼 + 一条嘴线
- 五种表情：待机（平嘴）、说话（嘴微张）、倾听（头微侧）、关切（眉下压）、高兴（弯嘴）
- 直径 96px 出现在设备右上或提示卡左侧，**不占主视觉**
- 红线：不穿白大褂、不拿听诊器、不出现任何医疗器械

## 9 禁止清单

- 不用纯黑纯白做大面积对比（除高对比模式）
- 不用渐变、玻璃模糊、霓虹发光
- 不用超过两层的投影
- 不用圆角胶囊包住正文（只包按钮与标签）
- 不用红色表达"重要"，红色只表达"求助 / 出错"
- 不用小于 18px 的字
- 不用英文缩写当按钮文字（"OK"、"Submit"）
