# 信息架构

## 1 一台设备，11 个节点，一条线

设备只有一个"页面"——当前该做的那件事。没有底部导航、没有个人中心、没有返回首页。

```
借出开机
  └─ 01 入口分流（选人）
       ├─ 02 建档 / 复诊（读卡，或人脸）
       ├─ 03 到达定位（beacon / 手工选）
       │    └─ 04 今日行程播报
       │         ├─ 05 取号排队
       │         ├─ 06 候诊（告知第几位 / 大约多久）
       │         ├─ 07 进诊室（替我说 / 复述校验）
       │         ├─ 08 检查规划（空腹、先后顺序）
       │         ├─ 09 执行与导航（步数化 / 大字地图）
       │         ├─ 10 缴费取药（医保三宫格）
       │         └─ 11 小结与回家（家属推送）
       └─ 归还 → 一键清空 → 下一位
```

## 2 三通道在同一节点上的差异

| 节点 | 通用（老人） | 视障 | 听障 |
| --- | --- | --- | --- |
| 01 入口分流 | 三个带文字的大按钮 | 长按任意位置开启语音引导，只说"按一下进入" | 三个按钮 + 一行说明"不用听，看字就行" |
| 03 定位 | 自动 + 大字显示当前位置 | 播报"您在门诊大厅，右手边是导诊台" | 文字 + 方向图标 |
| 04 行程 | 大字列表，一条一条念 | 语音念完，允许"再说一遍" | 文字列表 + 时间轴 |
| 06 候诊 | "前面还有 3 位，大约 20 分钟" | 只说剩余人数，不说分钟（数字更可靠） | 文字 + 倒计时条 |
| 07 诊室 | 复述校验卡 | 全程代说，患者只按确认 | **替我说**（核心屏） |
| 09 导航 | 大字方向 + 楼层图 | 步数 + 左手右手 | 方向图 + 距离 |
| 10 缴费 | 三宫格 + 一句人话 | 语音念金额，强调"医保替您付了大半" | 三宫格 + 明细可点开 |
| 11 小结 | "今天做了 3 件事，都做完了" | 语音小结 + 提醒下次复诊 | 文字小结 + 可分享 |

## 3 导航结构（屏幕上真正存在的东西）

- **主键区**：屏幕下方固定 3–4 个大按钮，位置永不变（肌肉记忆）
- **状态区**：屏幕顶部一条细状态栏（已开机 / 当前位置 / 时间 / 联网）
- **说话区**：屏幕中央，一次只说一件事，最多两行
- **求助**：右下角常驻一个红色「求助」按钮，长按 1.5 秒人工接入（防误触）
- **没有的东西**：返回上一级（不需要）、关闭（不需要）、设置（藏在长按里）

## 4 一次任务的信息量上限（硬限制）

| 项 | 上限 | 理由 |
| --- | --- | --- |
| 同屏文字块 | 3 个 | 超过 3 块，老人开始跳读 |
| 单块字数 | 18 字 | 1024px 宽、40px 字，两行以内 |
| 同屏按钮 | 4 个 | 第 5 个开始出现选择困难 |
| 单步操作 | 1 次点击 | 任何需要"两步才能完成"的动作都要拆成两屏 |

## 5 状态清单（每屏必备）

每一屏都必须设计这五种状态，缺一就是没做完：

| 状态 | 例子 |
| --- | --- |
| 正常 | 一切顺利 |
| 加载 | 读卡中（不超过 2 秒，超时给话术） |
| 不确定 | "您说的是心内还是心衰？" |
| 出错 | "没连上网，我再说一遍"（不出现错误码） |
| 完成 | 明确的"做完了"，带下一步 |

## 6 与旧版信息架构的关系

旧版（`medpal/docs/specs/device-ia.md`，26K）是工程视角的节点树，11 个节点保留；
**改变的是呈现**：从"节点树 + 面板"变成"一次一件事的全屏"。
工程侧的结构复用，视觉与交互全部重做。
