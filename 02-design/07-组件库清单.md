## 2 四态定义

- `default`: 常态. 无按压, 无选中, 无禁用.
- `pressed`: 按下 80ms 内出现反馈, 底色加深 8%, 不位移, 手指离开复原.
- `disabled`: 40% 透明度, 去饱和, 不接收点击, 不显示 loading.
- `selected`: teal-100 底 + teal-600 1.5px 边. 只对可选项有语义; 不可选组件也出变体, 但静态屏默认不出现.
- 命名统一: `state=default|pressed|disabled|selected`; 按钮加 `tone=primary|ghost|danger`; 小暖加 `expression=idle|talk|listen|concern|happy`.

## 4 G2 验收

- [ ] Figma 组件页有 9 个基础组件 + 1 个求助键变体, 全部是 component, 不是 frame.
- [ ] 每个组件有 4 个 variants, 命名与第 2 节一致.
- [ ] 所有颜色引用 04 token, 无手填 hex.
- [ ] 字号按 04 字阶或本表组件规格, 不新增 14px / 20px / 34px 这类就地数值.
- [ ] 无 emoji, 无系统默认字体, 无第二品牌色.
- [ ] 可点组件热区 >= 88 x 88; 主按钮高 120; 求助键 88 x 88.
- [ ] 每次按压 80ms 内可见反馈.
- [ ] T3 能直接用组件实例连原型, 0 追问.
- [ ] 组件页没有未使用的样式, 没有游离图层, 没有 `副本` / `final2`.
