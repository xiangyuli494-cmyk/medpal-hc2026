# 参考：旧原型截图（不是交付物）

这九张图是 2026-11-01 用旧原型（`medpal` 仓库的 `demo/v4.html` 那一套）跑出来的**过程记录**，用途只有一个：让 T2 知道"上一版长什么样、为什么被否掉"。

**它们不是高保真图，不要拿去交，也不要照着抄数字。**

## 为什么把它们挪到这里

- 尺寸是 **1680×900 / 1680×1120 的整页截图**（左屏列表 + 设备框 + 右批注），交上去叫"说明板"，不叫设计图
- 图上的字号（标题 39 / 正文 29）、按钮高度（98）、批注数字（84）是旧原型的值，**和现在 `02-design/04-视觉系统.md` 的字阶（40 / 26 / 22）与组件规格（主按钮 120、求助键 88×88）不是一套**
- 旧原型里没有"右下角常驻求助键"，也没有任何完成态绿——这两样现在是硬要求
