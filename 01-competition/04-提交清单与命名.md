## 2 匿名 Checklist（逐条打勾）

- [ ] 文件内**任何一页**都不出现姓名（含设计师署名、页脚、图层名残留）
- [ ] 不出现学校名、学院名、校徽、实验室名、项目编号
- [ ] 压缩包里没有 `.git` / `.github` / `.githooks` / `tools`（只有五件交付物）
- [ ] 不出现旧仓库的 GitHub 用户名（历史材料里出现过，**禁止在作品内出现任何仓库链接**）
- [ ] 不出现真实医院名、科室牌实拍、工牌、导诊单原图
- [ ] 不出现真实患者、真实身份证号、真实手机号（演示号码统一用 `138****6688`）
- [ ] 视频里不出镜的人脸已打码或只拍手部/背影
- [ ] PDF 元数据：清空 Author / Creator / Company（导出时选"不包含文档属性"）
- [ ] PNG 元数据：无 GPS、无设备序列号
- [ ] 文件名不含真实姓名以外的身份信息（姓名本身按主办方要求必须写在文件名里，这是合规项，不是泄密）
- [ ] 二维码 / 链接全部删除
- [ ] 字体版权：正文用系统字体或开源字体（思源黑体 / Noto Sans SC），不嵌商业字体

跑一遍脚本：`python tools/anon_check.py`

## 3 提交前 30 分钟检查

- [ ] 压缩包 ≤ 1GB（用 zip，不用 rar / 7z）
- [ ] 解压到一台干净电脑能打开全部文件（试一次，别只试自己的机器）
- [ ] 视频能在 Windows 自带播放器和手机上都播（H.264 + AAC，别用 HEVC）
- [ ] PDF 字体已嵌入（另存为 PDF/A 或勾选嵌入字体）
- [ ] 图片色域 sRGB（不要 Adobe RGB，评委屏幕会变灰）
- [ ] 每个文件夹里没有 `.DS_Store` / `Thumbs.db` / 草稿文件
- [ ] 上传后**下载回来自己再看一遍**，确认没传错版本
- [ ] 截图保存提交成功页（含时间戳）
