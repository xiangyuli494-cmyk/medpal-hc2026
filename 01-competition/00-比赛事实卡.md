# 比赛事实卡

> 来源：中国高等教育学会《关于举办 2026 新锐设计竞赛·华灿奖的通知》及赛区转发件（辽宁传媒学院 2026-10-10、长江大学传媒学院 2026-09-15、广外艺术学院 2026-10-12）。
> 口径冲突时，**以华灿奖官网 https://www.cahe.edu.cn/site/term/906.html 原文为准**。
> 核对时间：2026-11-01。

---

| 项 | 内容 |
| --- | --- |
| 赛事全称 | 2026 新锐设计竞赛·华灿奖 |
| 主办 | 中国高等教育学会、中华中山文化交流协会 |
| 承办 | 民革中央联络部、中国高等教育学会设计教育专业委员会 |

## 2 赛道结构

- **创意赛道**：6 个设计领域 × （高校学生组 / 青年设计师组）= 12 个竞赛小组
  1. 视觉传达设计
  2. 空间设计
  3. 产品设计
  4. **数字媒体设计**（用户界面 / 交互设计 / 数据可视化 / 游戏设计）← 我们报这里
  5. 时尚创意设计
  6. 交叉创新设计（科技+艺术 / 可持续 / 社会创新 / 未来概念）
- **定向主题赛道**：16 个专项主题，数量不限，截止 2027-03-05，直通总决赛
  - 9 号：领见启智·念创未来——AI 赋能创意设计与教育实践
  - 15 号：AI 智能体应用和跨境服务创新设计

## 3 参赛资格（必须逐条核对）

| 项 | 规则 |
| --- | --- |
| 年龄 | ≤ 45 周岁（1981-01-01 及以后出生） |
| 身份 | 高校在读学生 / 在职青年教师 / 青年设计师 |
| 团队 | **1 名第一作者 + ≤ 4 名成员**（共 5 人上限） |
| 指导教师 | 高校学生组 ≤ 2 人 |
| 作品数 | 创意赛道每人最多参与 5 件（第一作者与成员身份均计入）；定向赛道不限 |
| 赛区 | 按第一作者户籍 / 学习 / 工作所在地提交，**不得跨赛区重复提交** |
| 校赛 | 高校学生组作品**须经本校校赛选拔**方可进入赛区赛 |

## 5 提交规范（通用）

1. 文件命名：`赛道名称_作品名称_作者姓名`（例：`视觉传达设计_侨迹_张三`）；团队作品另附**成员分工**说明
2. 单个作品压缩包 **≤ 1GB**
3. 须签署《作品原创承诺书》随作品提交
4. **匿名要求**：作品中严禁出现参赛者姓名、所在单位等透露个人身份的信息

## 6 数字媒体设计的材料要求

> 提交**高保真设计图**及**交互流程图**；动态交互作品须附**演示视频**。

（其他领域仅作参考：视觉传达要 PDF 设计说明 + ≤2 分钟动态视频；交叉创新要完整项目提案含问题分析、解决方案、技术路径。）

## 7 奖项

| 奖项 | 数量 | 金额 |
| --- | --- | --- |
| 特等奖 | 4 项（可空缺，学生组 / 设计师组各 2） | 2 万元 / 项 |
| 现场评审一 / 二 / 三等奖 | 按 15% / 35% / 50% 分配 | — |
| 路演奖 | 6 项（两组各 3） | 1 万元 / 项 |

获奖权益：入驻「华灿OPC两岸设计师生态社区」、人才库、创业辅导、投资孵化、算力支持等。

## 8 违规与权属

- 抄袭剽窃、侵犯知识产权、同一作品已获前 10 届华灿奖奖项 → 取消资格 / 撤销奖项 / 三年禁赛
- **获奖作品著作权由主办方行使**（复制权、展览权、信息网络传播权等），须签授权协议，拒签视为放弃获奖资格
- 因作品引发的知识产权纠纷由参赛者及所在单位承担
