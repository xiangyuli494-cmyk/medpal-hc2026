## 2 为什么是数字媒体设计·交互设计

1. **材料要求完全对得上**。官方要「高保真设计图 + 交互流程图 + 演示视频」，正是我们手里东西该被翻译成的形状；换成产品设计就得交三视图和工艺说明，换成交叉创新就得交完整提案——都不是我们的强项形态。
2. **我们真的有一个能点的东西**。绝大多数参赛作品是一组静态图；我们能当场切通道、切模式、演示降级。这是交互设计组的稀缺项。
3. **评委能看懂差异化**。同一组里，别人做的是"好看的 App"，我们做的是"三种身体条件、三套交互契约、同一台公共设备"。这个差异在第一张图就能看出来。

## 3 作品定位（一句话版本，全组统一口径）

> **一台在门诊服务台借出、离院前归还的手持陪诊机，替不会用手机的老人走完院内全流程。**

对外**不说**的话：

| 不说 | 改说 |
| --- | --- |
| 医疗决策智能体 | 医嘱回放 / 流程协助 |
| 分诊、诊断、建议用药 | 帮您把医生的话记下来、讲清楚 |
| AI 判断 | 医生说……（原话为准） |
| 老人不会用手机是他们的缺陷 | 设备不该要求用户先学会用手机 |

## 4 三个差异点（答辩与展板都围绕这三条）

1. **通道即契约，不是换肤**
   老人：大字 + 记忆辅助 + 复述校验；视障：全程语音、零交互、步数化导航；听障：文字优先 + 「替我说」把文字念给医生听。
   三套不是同一个界面的三种配色，而是三种完全不同的交互契约。
2. **系统不会猜**
   认不准就标出来问：ASR 置信度 0.41、剂量 0.5g / 5g、手写字模糊——全部走"求证"，不走"推断"。演示里可以主动制造故障。
3. **AI 是可被检查的**
   屏幕上出现的每一句话，都能展开成 事实 → 模板 → 润色 → 红线校验 → 出口 五段。评委当场能验证"用了 AI 但可控"。

## 5 与小暖形象的关系

小暖是设备上的虚拟陪伴角色，**不是客服弹窗**，也不是医生。

- 不穿白大褂、不戴听诊器、不出现任何医疗器械
- 五种表情：待机 / 说话 / 倾听 / 关切 / 高兴
- 形象上就先说清楚：她陪您跑流程，不负责看病
