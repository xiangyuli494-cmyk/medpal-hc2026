## 0 为什么这份不能先"写出来"

- 原话卡是设计说明的证据链：`06-五人分工` 第 30 行「每一句判断背后都有一张原话卡」，第 166 行「文案分歧 → T4 拍板，判据是原话卡里有没有依据」。
- 评审会追问「这句话谁说的、什么时候、在哪儿」。**编的原话经不起一句追问**，会让说明 PDF 第二章整体作废。
- 因此：**逐字原话 / 转述 / 机器初稿** 三者分开记，只有逐字原话能进卡。

> "我在做一个学校的设计作业，想听听您去医院的实际经历。只记笔记；写的时候不写您全名，写'王女士，__ 岁'这样；任何问题不想答就跳过。"

### 2.3 五个必问（对应 `05-research/访谈提纲.md`）

1. 上一次您自己去医院是什么时候？看什么科？
2. 从进门到离开，您一共走了哪些地方？**哪一步最麻烦？当时您是怎么知道下一步该去哪的？**
3. 医生说的话您一般怎么记住？有没有回家以后想不起医生怎么交代的？
4. 缴费单上的数字您看得懂吗？医保报了多少，您是当场知道还是回家问子女？
5. 如果服务台能借您一台小平板、走的时候还回去，您愿意用吗？担心什么？家里人想不想知道您到没到医院？

### 2.4 记录规范

- 一句原话一张卡；方言、口头语全保留，**一个字都不改**；记不清的整句丢掉，不补全。
- **逐字 / 转述 / 机器初稿分开记**：只有逐字原话能入卡。
- 场景具体；日期写访谈当天。
- **脱敏**：不写姓名、关系称谓、住址、医院名、医生名；科室对外写"某科"。
- 录音只作内部转写：不入库、不进提交包、整理完删除。
