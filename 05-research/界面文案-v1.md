## 0 三条硬规则

| # | 规则 | 依据 | 反例 |
| --- | --- | --- | --- |
| 1 | 一屏只有一个 display（56px）；主话 ≤ 18 字 | `02-design/04-视觉系统.md` §3、`02-design/02-信息架构.md` §4 | 一屏两句"欢迎使用""请选择"，等于没有重点 |
| 2 | 不用界面黑话：点击 / 下一步 / 操作 / 滑动 / 扫码 / 提交 / 返回 / 设置 | `06-五人分工` T4 验收 | "请点击下一步" |
| 3 | 不承诺、不诊断、不吓人：只说我"记着 / 提醒 / 帮您叫人" | `01-competition/05-风险与合规.md` §2 | "有我在您不会走丢" |

**T4 拍板的一条边界**：「点一下 / 按住 / 松开」是老人嘴里的动作词，**保留**；「点击 / 操作」是界面词，**禁用**。判据是原话卡里老人自己说不说这个词（现有原话卡待采，先用这条临时口径，采到后回填依据）。

## 1 全站用语

| 项 | 口径 | 说明 |
| --- | --- | --- |
| 称呼 | 对患者一律「您」；对家人说「您家里人」 | 界面里不出现"用户 / 患者 / 老人" |
| 自称 | 「我」，指小暖；不自称"本设备 / 系统" | "系统"只在设计说明里出现 |
| 数字 | 屏上写阿拉伯数字；朗读时转中文 | 386 → "三百八十六块"；9:40 → "九点四十"；18 步 → "十八步"；二楼 |
| 金额单位 | 主话用「块」（口语），明细表用「元」（对齐结算单） | 两者同时出现时，主话在上、明细在下，不加换算说明 |
| 动作 | 按住 / 松开 / 选一个 / 看这里 | 按钮上不写动作说明，只写结果（"念给医生听"） |
| 时间 | 24 小时制，冒号分隔 | 推送卡时间放右上，`sm` 22px |
| 语气 | 短句、陈述、不感叹、不卖萌 | 不用"呀 / 哦 / 啦"；不用"请稍候"，直接说"等两秒" |
| 英文 | 界面不出现英文；「App」只在页脚出现一次（家属端） | 图标用自绘，不用 emoji |

## 5 大字 / 高对比模式的文案要求

- 大字模式（根字号 23px，全屏 ×1.15）：上表所有单块文案**不得折行超过两行**；超了就删词，不加省略号。
- 高对比模式（黑底白字）：状态不能只靠颜色区分，文案要自带状态词——「已经做完」「还没做」「现在去」，不写"绿色表示完成"。
- 数字一律等宽（tabular-nums），金额、步数、时间不许跳动。
