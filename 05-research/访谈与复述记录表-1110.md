## 4 60+ 复述测试（只读主话+副话，不解释、不指屏）

| 屏 | 主话（照读） | 测试人 A 第一句复述 | 能/不能 | 测试人 B 第一句复述 | 能/不能 |

| 01 | 您好，我是小暖。今天是谁来看病？ | | ☐能 ☐不能 | | ☐能 ☐不能 |

| 06 | 让家里人放心，不盯着您。 | | ☐能 ☐不能 | | ☐能 ☐不能 |
| E1 | 我没听清，您说的是哪个？ | | ☐能 ☐不能 | | ☐能 ☐不能 |

**判定标准（写死，别靠感觉）**：**能** = 用自己的话说出「对象 + 动作」（允许语序/方言变化、允许要求再读一遍）；**不能** = 要人解释、复述出术语、只重复个别词、或把意思理解成别的事。

**读主话 + 副话，两遍读完再让对方复述**：只测主话会高估"懂"。例：屏 01 读完"您好，我是小暖"再读"今天是谁来看病？选一个就行，选错了能重选。"；屏 04 读完"我复述一遍，您听听对不对"再读"今天看心血管内科，要做两件事……"。

**第 3 位（C）也要做**：68 岁同样属 60+；当天做不了就写明"未做及原因 + 补测时间"，不能空着当完成。
