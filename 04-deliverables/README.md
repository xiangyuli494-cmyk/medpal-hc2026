# 交付物（最终要交出去的东西）

这个目录里放的是**最终交出去的文件**，不是工作文件。工作文件留在 `02-design/`。

例外只有一类：**纯文本源文件可以跟在交付物旁边**（如 `02-流程图/src/*.mmd`）。判定标准是"能不能在 PR 里逐行 review"——能，就可以放这里；不能（psd / ai / fig / procreate / 视频工程），一律留在本地盘，不进仓库。

大文件（视频成片、展板 PDF）走云盘交付，仓库只留文件名与校验值，见第 4 节。

## 目录

| 目录 | 内容 | 规格 |
| --- | --- | --- |
| `01-高保真图/` | 7 张（01–06 + E1），不多不少 | PNG @2x（2048×1200），sRGB，纯设备屏无外框无批注 |
| `02-流程图/` | 主流程 / 三通道 / 异常降级 | 导出 PDF 或 PNG（横版）；**源文件用 Mermaid 文本放 `src/*.mmd`**，PR 里能逐行批注。注意 GitHub **不渲染独立 `.mmd`**（只渲染 `.md` 里的 mermaid 围栏），预览走 VS Code Mermaid 插件 / mermaid.live / `mmdc` |
| `03-视频/` | 演示视频 | MP4，H.264 + AAC，1080p，≤ 2 分钟。**成片不进 git**（`.gitignore` 已忽略 `*.mp4`），走云盘，这里只留 `素材清单.md`、`分镜表.md` 和一行校验值 |
| `04-展板/` | A0 竖版 | PDF 矢量或 300dpi |
| `05-设计说明/` | 设计说明 | PDF，≤ 12 页 |

## 命名

```text
<赛道>_<作品>_<第一作者>_<序号><屏名>@2x.png
数字媒体设计_小暖_张三_01入口分流@2x.png
```

## 打包前

1. 跑 `python tools/anon_check.py`（注意：`04-deliverables/` 默认跳过，交付文件需人工再检查一遍元数据）
2. 清空 PDF 文档属性（Author / Creator / Company）
3. 确认图片无 GPS、无设备名
4. `zip -r 数字媒体设计_小暖_张三.zip 数字媒体设计_小暖_张三/`
5. 检查压缩包 ≤ 1GB
6. 上传 → 下载回来 → 自己再看一遍

## 留档

上传成功后，把「提交成功页截图 + 压缩包的 SHA256」放在本目录的 `_提交记录.md` 里，防止评审期被要求补材料时手忙脚乱。
