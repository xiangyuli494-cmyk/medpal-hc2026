# 交付物（最终要交出去的东西）

这个目录里放的是**最终交出去的文件**，不是工作文件。工作文件留在 `02-design/`。

## 目录

| 目录 | 内容 | 规格 |
| --- | --- | --- |
| `01-高保真图/` | 7 张（01–06 + E1），不多不少 | PNG @2x（2048×1200），sRGB，纯设备屏无外框无批注 |
| `02-流程图/` | 主流程 / 三通道 / 异常降级 | PDF 或 PNG，横版 |
| `03-视频/` | 演示视频 | MP4，H.264 + AAC，1080p，内部目标 90±5 秒，官方时长上限待核 |
| `04-展板/` | 主视觉 1 + 细节 3，共 4 张；内部目标 A0 竖版，官方规格待核 | PDF 矢量或 300dpi |
| `05-设计说明/` | 设计说明 | PDF，≤ 12 页 |

## 命名

```text
<赛道>_<作品>_<第一作者>_<序号><屏名>@2x.png
数字媒体设计_小暖_张三_01入口分流@2x.png
```

## 打包前

1. 跑 `python tools/anon_check.py`（`04-deliverables/` **会被扫**，这里出现的身份痕迹算硬伤；脚本读不了 PDF/PNG 内容，图片与 PDF 的元数据仍需按下一条人工清）
2. 清空 PDF 文档属性（Author / Creator / Company）
3. 确认图片无 GPS、无设备名；人工回看 PNG/PDF/视频两遍，脚本通过不等于匿名终检通过
4. `zip -r 数字媒体设计_小暖_张三.zip 数字媒体设计_小暖_张三/`
5. 检查压缩包 ≤ 1GB
6. 上传 → 下载回来 → 自己再看一遍

## 留档

上传成功后，把「提交成功页截图 + 压缩包的 SHA256」放在本目录的 `_提交记录.md` 里，防止评审期被要求补材料时手忙脚乱。

提交包不得包含 `.git`、`.github`、`.githooks`、`tools`、报名原始截图或原始实拍素材。仓库历史身份单列，不作为作品文件硬伤；内部文档和真实作者信息不进入匿名图内。目录中出现文件不代表已验收，须看七屏验收表与各线签字。
