# 小暖 · 本地交互概念演示

双击 `index.html`，或用静态服务打开本目录。无需构建、登录或联网。使用桌面 Chrome / Edge；设备屏按1024×600比例缩放，展示时建议桌面全屏。

上方七个页签用于评审对照，不是设备功能。主线可从入口选择通用或听障通道，核对医嘱、查看费用、自愿发送小结、归还清空。视障通道可由入口任意位置按住2秒进入；进入后松手，再按住1.5秒求助。模拟说话输入「再说一遍」「等等」「到了」「对」「好」「不对」「求助」演示对应反馈；这里没有真正识别麦克风。

03初次进入没有选择，至少选一句才能「念给医生听」，按选择顺序组合；导出的03静态图展示两个芯片选中状态。开启「演示语音」后可调用浏览器中文语音包，语音是否可用取决于本机。听障通道的医生回复用文字示意，不要求使用者听到设备声音。

06只在明确同意后标记通知示例；页签也可单独查看该设计。画面中的「关闭通知」有可点击入口。拒绝发送仍可正常归还。归还仅清空原型内存状态，不代表已验证真实后台数据删除。

本原型演示界面与预设数据，不连接医院、支付、真实导航、微信推送或患者账户。图内时间、金额和王医生均为样例。七屏对应关键设计状态，完整11节点逻辑另见三张流程图；未把每个节点再做成独立页面。

复现导出：`python tools/build_screens.py --render`（从仓库根目录运行，需要Pillow、Playwright和Edge）。先在本目录启动静态服务，再运行 `python tools/check_prototype.py --url http://127.0.0.1:8768/ --qa <记录目录>`。

说明与展板：运行 `python tools/build_design_documents.py --font <开源中文TrueType字体> --qa <记录目录>`，需要reportlab、PyMuPDF和Pillow。正式PNG和本目录的screens.js由同一份源生成，不手改screens.js。
