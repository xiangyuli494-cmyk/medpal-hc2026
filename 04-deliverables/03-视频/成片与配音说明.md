## 复现

需要Python的edge-tts、Playwright、Pillow、NumPy、OpenCV，以及FFmpeg/ffprobe和中文TrueType字体。MP4按仓库规则不进入Git，仓库保留本说明、SRT、配音稿和生成脚本。

```text
python tools/prepare_demo_video.py --output <本地输出目录> --proxy <可选代理>
python tools/prepare_demo_video.py --output <同目录> --screens
python tools/build_demo_video.py --output <同目录> --media-root <八段视频目录> --font <开源中文TrueType字体> --render
```

首次运行需生成配音和原型状态。修改配音词后应重新生成对应`work/voice-*.mp3`及JSON，避免沿用旧缓存；脚本不会更改原视频。场景文件映射见`tools/build_demo_video.py`的SOURCE，修改映射即可使用重命名素材。
