## 一、背景（P2，约 500 字）

老年人独自就医的困难，不是"不会用手机"，而是**每一步都要自己判断下一步去哪**：挂号、建档、定位、行程、取号、候诊、诊室、检查、缴费、取药、回家——11 个节点串行，信息分散在窗口、单据、屏幕和"问人"里。

我们的访谈里，A（70 岁）与 B（62 岁，家属）都提到：导航靠"看指示牌，或者问那个导医"（卡 3）、"问人，一般都是问人"（卡 1）；B 还描述了"挂号、交费、化验、取药，自己到窗口排队，还要等结果"（卡 2）——流程不复杂，复杂的是**多次排队与等待**。

现有适老化产品大多是在手机 App 上打补丁；这个作品换载体：**服务台借出、离院归还的手持陪诊机**（`01-competition/01-赛道与作品定位.md`）。它只做三件事：把"下一步"连续地给出来、把医生的话记下来并请您确认、把流程与钱说成人话。

## 二、研究（P3–P4，约 700 字）

**方法**：2026 年 11 月，访谈 3 位家人（A：70 岁女性；B：62 岁男性，家属视角；C：另一位长辈），半结构访谈围绕最近一次独自就医。样本为熟人（**非典型样本**），结论只作设计依据，不作统计推断。访谈不录音像；B 的通话经同意后仅作转写，文字整理后删除录音。

**六个发现**（详见 `05-research/原话卡-v1.md` 12 张卡）：
1. "下一步"没有人为你负责——靠指示牌 + 问人（卡 1、3）；
2. 一次门诊是"排队 + 等待"的循环（卡 2）；
3. 记忆最先丢：连"上次是几月"都要想一下（卡 4、5）；
4. 钱要先给结论，但别替用户假设恐惧——C 说没有因为不知花多少就少做检查（卡 7、8）；
5. 老人**愿意当场纠错**（C："会"），不用自助机是**"不会"不是"不敢"**（卡 6、9）；
6. 家属要知道到**"科室"**这一级（卡 11、12）。

**这些发现直接决定后面的设计**：屏 04 复述校验、屏 02/09 分段导航、屏 05 三宫格、屏 06 通知粒度。

## 三、方案（P5–P6，约 800 字）

**形态**：服务台借出 → 离院归还 → 一键清空；押金与借用记录随换机转移（B 的顾虑"要交押金，弄坏了要赔"直接写进借出说明，卡 10）。

**三通道**：同一节点、三种呈现、同一次决定——
- 通用（老人）：看，大字，一次一件事；
- 视障：听，全黑屏 + 步数化导航（"往前走十八步"）；
- 听障：看字 + **替我说**（点一句，设备念给医生听）。

**一屏一件事**：没有底部导航、没有个人中心、没有返回首页；每屏右下角求助键 88×88，长按 1.5 秒接人工（"任何一步都能退出"的物理保障）。

**七屏**（`02-design/05-屏幕清单.md`）：01 入口分流 / 02 视障语音通道 / 03 替我说 / 04 复述校验 / 05 医保三宫格 / 06 家属端 / E1 我没听清。

## 四、交互（P7–P8，约 800 字）

**主流程**：借出 · 开机 → 01 入口分流 → 是否建档（**判断 C**）→ 02 复诊/首诊 → 03 到达定位 → 04 今日行程 → 05 取号 → 06 候诊 → 07 进诊室（通道分岔，不是判断点）→ 08 检查规划 → 09 执行与导航 → 还有没做完的检查（**判断 N**）→ 10 缴费取药 → 11 小结 → 家属端推送 → 归还 · 一键清空。

真判断点只有两个（C、N），都是是/否两条出路；07 是按通道三选一的分流，不是用户要做的新决定（`04-deliverables/02-流程图/src/主流程.mmd`）。

**三通道契约**：进入（点磁贴 / 长按任意处 2 秒）、获取信息（看 / 听 / 看字）、确认（对，就是这样 / 按一下 / 明白了）、出错（大字 + 一个按钮 / 语音重播 / 大字）、打断（求助键 1.5s / 任意位置长按）、节奏（用户控制 / 语音说完才走 / 用户控制）。

**6 条异常降级**（兜底文案见 `05-research/界面文案-v1.md` §4）：
1. 断网 → "网断了，行程和导航还能用"（离线优先）；
2. 置信 <0.6 → 不猜，两个候选放大并列（E1）；
3. 越界提问 → "这个我不能答。我帮您叫护士？"；
4. 90 秒无操作 → "我在这，您慢慢来"（不弹窗不催）；
5. 电量 <15% → 回服务台换机，记录不丢；
6. 未归还/流程未完成 → 收尾清单推给家属端。

**E1 是证据位**：系统的不确定是可见的（"我没听清，您说的是哪个？"）——C 说"会"当场说不对，说明这个问法成立。

## 五、技术可行性（P9，约 450 字）

只写"能兜住"的，不写"AI 多强"：

1. **离线优先**：行程 / 导航 / 医保三宫格全部本地；断网时顶部常驻"离线也能用"；
2. **语音识别设置信阈值**：<0.6 不猜，候选放大并列，由用户指认；
3. **本地加密 + 离院一键清空**：不做云端留存，数据最小化；
4. **不接诊断、不给用药建议**：只回放医生原话、只做流程协助。

区分"可演示"与"设计假设"：ASR 与导航精度是演示假设；离线流程、状态机、清空逻辑是可演示的。不承诺准确率数字，不写"我们训练了模型"。

## 六、边界与伦理（P10，约 500 字）

自己给自己划红线（`01-competition/05-风险与合规.md` §2）：

1. 不诊断；2. 不建议用药；3. 不替代人（只承诺提醒，不承诺安全）；4. 不监控（家属端只报节点，不做定位）；5. 不冒充医护（形象无白大褂/听诊器）；6. 数据最小化（离院清空）。

**复述校验是道德支点**：系统会承认自己可能记错（屏 04"我复述一遍，您听听对不对"），AI 的输出必须由人确认。**家属端三条原则**：只报节点、不做定位、可随时关闭；C 说愿意让家人知道、并且"到科室"就够（卡 11、12）。**授权条款**：获奖作品著作权由主办方行使，已向全组通报（`05-风险与合规.md` §4）。
